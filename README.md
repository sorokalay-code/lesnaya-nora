# Лесная нора

Одиночная 3D игра о жизни дикой крольчихи. Проект написан на TypeScript и Three.js, запускается как обычный фронтенд через Vite.

## Запуск

```powershell
pnpm install
pnpm run dev
```

Откройте адрес, который покажет Vite. Для проверки сборки: `pnpm run build`.

## Игра

- **WASD** — движение, **Shift** — бег, **Space** — прыжок.
- Перетаскивайте мышь для вращения камеры; колесо меняет расстояние.
- **E** — собрать растение или поговорить с кролом.
- **G** — съесть еду из запасов.
- **B** — выкопать нору или расширить существующую.
- **H** — скрыться в норе или выйти; **R** — поспать рядом с ней.
- **P** — справить нужду; **F** — покормить крольчат у норы.
- **M** — карта, **J** — дневник, **F5** — сохранить.

У каждого партнёра есть гены, характер, семья и предпочтения. Разговоры и подарки повышают доверие. При достаточной совместимости можно создать семью. Крольчата наследуют признаки родителей, нуждаются в кормлении и со временем взрослеют. Хищники активнее ночью; в огородах встречаются сторожевые псы. Мир, места растений и кролики определяются случайным seed. Дни, сезоны и погода сменяются по ходу игры.

Сохранение хранится в `localStorage` браузера. Запись происходит автоматически каждые 30 секунд и вручную по кнопке или F5. Для загрузки нажмите «Продолжить сохранение» на начальном экране.

Модели построены из геометрии Three.js. Звуки синтезируются Web Audio API после первого нажатия в игре; внешние звуковые файлы и изображения не требуются.
